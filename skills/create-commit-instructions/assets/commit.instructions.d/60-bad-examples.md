## BAD EXAMPLES

The following are unacceptable - never generate messages like these:

| Bad message                         | Why it is wrong                                      |
| ----------------------------------- | ---------------------------------------------------- |
| `update stuff`                      | Vague - conveys no intent                            |
| `fix things`                        | Vague - does not identify the fixed behavior         |
| `feat: Added new API.`              | Past tense, uppercase description, trailing period   |
| `chore: add public behavior`        | Uses `chore` for a behavior change                   |
| `refactor: fix crash on startup`    | Uses `refactor` for a bug fix                        |
| `docs(readme/docs): update docs`    | Multi-part scope and vague description               |
| `feat: massive rewrite`             | Vague and likely too broad for one commit            |
| `fix: wip`                          | WIP wording is never acceptable                      |
